# a-takip

Proje ve görev takibi uygulaması. Tek sayfalık web uygulaması; veriler Firebase Firestore'da tutulur.

- `index.html` – uygulama
- `shim.js` – Firestore veri katmanı
- `config.js` – Firebase proje ayarları
- `seed-demo.json` – demo şirket verisi (ilk hesap açıldığında yüklenir)

Giriş: ilk açılışta hesap oluşturulur. İlk açılan hesap uygulama sahibidir. 1111 demo şirketi açar.
